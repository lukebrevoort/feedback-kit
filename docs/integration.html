FEEDBACK KIT · V0.1

One small UI, complete bug context.

The host app decides what state is useful. The kit captures and sanitizes it, an optional agent scopes the issue through a short conversation, and a server-only adapter creates the Linear ticket.

1

Drop in the widget

  • Floating feedback trigger
  • Automatic screenshot
  • Multi-element picker
  • Paste or upload images
2

Capture app context

  • App-owned getState()
  • Two-pass secret redaction
  • Route, browser, viewport
  • Version and environment
3

Scope with an agent

  • One question at a time
  • Reproduction steps
  • Acceptance criteria
  • Uncertainty preserved
4

Create the ticket

  • Server-only credentials
  • Private screenshot upload
  • Structured Linear issue
  • Conversation attached
Portable by design The report, scoper, and submission contracts are framework-neutral. React and OpenAI are adapters, not permanent dependencies; another UI, model provider, or ticket system can implement the same boundaries.

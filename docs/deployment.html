The demo is a static Vite app on Vercel. It sends versioned reports to a small Railway API, which can run in safe demo mode or connect to OpenAI and Linear when server-side credentials are present.

Credentials stay server-side. Without them, deterministic demo adapters keep the full flow testable.

Deploy order

  1. Deploy the repository to Railway using railway.toml.
  2. Copy the Railway public URL.
  3. Set VITE_FEEDBACK_API_URL in Vercel.
  4. Set Railway ALLOWED_ORIGINS to the Vercel origin.
  5. Deploy the same main branch to Vercel.

Optional production integrations

  • OPENAI_API_KEY enables model-backed issue scoping.
  • OPENAI_FEEDBACK_MODEL selects the scoping model.
  • LINEAR_API_KEY and LINEAR_TEAM_ID enable issue creation.
/health reports which integrations are active.
